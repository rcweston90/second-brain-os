# 5-journal

**Purpose:** Time-series daily notes. Append-only, structurally different from everything else — kept separate on purpose.

**Rule:** One file per day, `YYYY-MM-DD.md`. Don't reorganize; this is a log, not a knowledge base. It's also where *self*-detail belongs — dated and honest about being a snapshot — rather than in timeless wiki pages.

**Lifecycle question this folder answers:** *When did this happen?*
