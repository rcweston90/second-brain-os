# 1-projects

**Purpose:** Active work with a defined outcome and an end. Time-bound.

**Rule:** One subfolder per project, each with an `_index.md` landing page (outcome in one sentence, deadline, status, and a dated decisions log). A project is something you'd say "done" about.

**vs. 2-areas:** Projects *end* (ship the redesign, finish the interview loop). Areas *continue* (career, finances). If there's no finish line, it's an area.

**Aging out:** No activity in 90 days → move the project folder to `6-archive/projects/`.

**Lifecycle question this folder answers:** *Am I actively working toward an outcome here?*
