# 3-library

**Purpose:** Consumed reference — material someone else produced that you consult but don't actively change.

**Contents:** `documents/`, `frameworks/`, `imports/`, `devdocs/`, `transcripts/`, `clippings/`.

**Rule:** Cite the source. You read/reference it; you don't author it. If you're producing it, it belongs in `4-studio`.

**A note on the boundary with brain-research:** a *clipping* is someone else's article you consume (and might productionize into your own writing). Research *about how your own system works* is a different genre and lives in `_meta/research/`, not here.

**Lifecycle question this folder answers:** *Is this input I consult, authored by someone else?*
