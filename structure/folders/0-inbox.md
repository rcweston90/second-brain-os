# 0-inbox

**Purpose:** Unprocessed capture. Anything new lands here first.

**Rule:** Weekly inbox-zero pass. For each note decide:
- Active work with an outcome? → `1-projects/<project>/`
- Ongoing responsibility / identity / reference you maintain? → `2-areas/`
- Consumed reference (someone else's)? → `3-library/`
- Your own output (writing / sketch / spec)? → `4-studio/`
- Not worth keeping? → delete (or `6-archive/`)

**Inputs flowing here:** web clipper, a capture hotkey, manual notes, scrapes.

**Lifecycle question this folder answers:** *Have I processed this yet?*

---

## Staging subfolders

These are **triage-staging buckets, not permanent homes** — they cluster the backlog so the weekly pass is faster. The end state is still an empty-ish inbox; each bucket drains toward its lifecycle home over time.

| Subfolder | Holds | Drains toward |
|---|---|---|
| `articles/` | Web article / think-piece clippings | `3-library/` |
| `tools/` | Repos & product/tool captures | `3-library/` |
| `ai-agents/` | AI / agent workflow notes & skill captures | `3-library/` or `4-studio/` |
| `design/` | Craft notes, references, reflections | `2-areas/` or `4-studio/` |
| `<project>/` | Material for one active project | `1-projects/<project>/` (promote when triaged) |
| `checklists/` | Process checklists & workflow references | `2-areas/` or `3-library/` |
| `personal/` | Personal & sensitive | `2-areas/` — *credentials → `2-areas/identity/codes/`* |
| `links/` | Link dumps & reading lists | `2-areas/lists/` |
| `misc/` | Unclassifiable scraps | triage individually |
