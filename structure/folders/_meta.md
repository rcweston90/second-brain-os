# _meta — system artifacts

**Purpose:** the artifacts *about* the vault — how it runs, **why** it's built this way (decision records), and the audits that keep it honest. Not creative output (that's `4-studio`); setup and operating guides for a system live here, in the system's settings.

**Contents:**
- **Operating guides** — the replication guide (the vault itself) and the decision-OS setup guide.
- `IA-decisions/` — dated architecture decision records: the running "why" log. Each records *what was decided and why*, not procedure.
- `research/` — the brain's research journal (evidence syntheses about how the system should work).
- **Audits & diagnostics** — snapshots of the corpus, not decisions.
- **Machinery** — Bases views, canvases, and loop state files.

The two dashboards split the work: an *operational* one (what's owed now) and an *architectural* one — the system map. See **[../system-map.md](../system-map.md)** for the diagrams.

**Lifecycle question this folder answers:** *Is this about how the system itself runs?*
