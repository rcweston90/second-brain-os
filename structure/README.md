# Structure — the system, natively

This folder lets you browse the Second Brain OS the way it actually exists on disk: the per-folder `_about.md` files that tell the agent where everything belongs, and the mermaid maps of how the pieces connect. It's the annotated skeleton — no personal content, just the architecture.

Start here:

- **[system-map.md](system-map.md)** — the whole machine in two diagrams: the capture → ship flow with its gates, and the decision-system gates.
- **[vault-map.md](vault-map.md)** — the seven lifecycle folders and the three distinctions that make filing nearly automatic.
- **[folders/](folders/)** — the actual `_about.md` for each folder: what it holds, its one rule, and the lifecycle question it answers. These are what an agent reads to know where a note belongs.

Every file here is generalized from a live vault — names, projects, and private content removed; only patterns kept. The full rationale, conventions, and build order are in the root **[GUIDE.md](../GUIDE.md)**.
